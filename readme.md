# LinkedIn Banner Generator

A React application to generate professional LinkedIn banners based on your profile data.

---

## Features

- **10 Unique Themes:** Choose from Modern, Minimalist, Corporate, Startup, and more.
- **Fully Customizable:** Edit your name, role, tagline, links, and tech stack in real-time.
- **Capture Mode:** Dedicated clean view for taking high-quality screenshots.
- **Responsive Design:** Built with Tailwind CSS.

---

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm (v6 or higher)

### Installation

1. **Clone this repository or download the files.**
2. **Install dependencies:**
   ```bash
   npm install
   ```
3. **Start the development server:**
   ```bash
   npm run dev
   ```
4. **Open your browser to** [http://localhost:5173](http://localhost:5173)

---

## Tech Stack

- React
- Vite
- Tailwind CSS
- Lucide React (Icons)
